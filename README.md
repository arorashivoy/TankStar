# TankStar

**Archived and incomplete** — the last commit, January 2023, is titled "game done
kinda", which is the honest description.

A two-player artillery game in Java with [libGDX](https://libgdx.com) and Box2D,
written over late 2022 as a university object-oriented programming project. Turn-based
tank duelling on a Tiled map.

Implemented: splash, main menu, tank selection, pause and game screens; Box2D physics
bodies built from Tiled object layers; tank movement and firing; game saving. Rough
edges throughout, and it was never balanced or finished.

Run with `./gradlew desktop:run`.
